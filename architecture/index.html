📈 Правила увеличения охвата ДЛЯ ВСЕХ АККАУНТОВ живой охват важнее числа подписчиков
  • Reels / видео — драйвер №1. Алгоритмы сильнее всего разгоняют короткие видео — приоритет Reels во всех аккаунтах.
  • Активная живая аудитория. Платформа показывает контент шире, когда подписчики реально реагируют (лайки, комменты, досмотры), а не просто «числятся».
  • Вычистили ботов и мёртвых подписчиков. Убрали накрутку из аккаунтов, чтобы охват шёл на живых людей — заняло много времени, но это база честного роста.
  • Вовлечение важнее количества. Лучше меньше подписчиков, но живых — под них алгоритм и раздаёт охват.

🎬 Как мы делаем AI-блогеров и видео

Единый продакшн-процесс для всех роликов — Лера Морозкина, новые блогеры, Мишка Ливси, видео-посты. Согласуем поэтапно, правим покадрово — чтобы не жечь кредиты.
1
Идея
Концепт ролика: о чём, вайб, длина, на какой площадке выходит.
→
2
Покадровый сценарий
Разбиваем на кадры/шоты: сцена, действие, длительность, реплика.
утвердить ДО картинок
→
3
Лист персонажа (Soul ID)
Фиксируем внешность героя один раз — якорь для всех кадров. Внешность заперта, движение — отдельно.
→
4
Сториборд (картинки)
На каждый кадр — статичная раскадровка от Soul ID (дешёвая модель).
утвердить визуал ДО анимации
→
5
Анимация + склейка
Оживляем короткими клипами 3–4 сек с чейнингом, затем склеиваем в ролик.
→
6
Правки покадрово
Меняем только затронутый клип и ре-склеиваем. Не перегенерируем весь ролик.
Правила пайплайна
  • Согласование поэтапно — как с постами: идея → сценарий → сториборд → анимация, каждый шаг отдельно.
  • Дорогое — после дешёвого: утверждаем на статичных кадрах, только потом платная анимация.
  • Soul ID переиспользуем — у существующего героя не создаём заново, персонаж не «плывёт» между кадрами.
  • Правки на уровне кадра, не всего ролика — главная экономия кредитов на видео.
